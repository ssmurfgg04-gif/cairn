    How to use Cairn

    Cairn keeps your whole studio's work on every computer - no upload sites, no hard drives in bags. The six things below are everything you need.

    1

    Add your project

    Click Add project folder and pick the folder where your project lives - the one with your footage.

    Your teammates do the same on their computers and join with a code (see step 5).

    Advanced / Command line

    cairn attach /path/to/project

    2

    Open your normal folder

    The project folder works like any folder on your computer. Open it in Explorer or Finder - Premiere and DaVinci see the same files.

    Home → Open folder takes you straight there.

    3

    Work normally

    Edit, save, move files as you always do. Cairn copies every change to your other computers in the background.

    The dot at the top says Working… while copies are in flight - you can keep editing.

    4

    Make a file available offline

    Files that live on other computers show Online only in Files. Open the row's ••• menu and choose Make available - the full file copies onto this computer.

    Going on a shoot or a flight? Also choose Keep on this computer so it never gets cleaned up.

    5

    Share with a teammate

    Open More → Connect, click Generate code, and send the code to your teammate. They paste it in the same place on their computer.

    Sharing one file instead? The row's ••• menu has Share project link.

    Advanced / Command line

    cairn login --server <server> --code <code> --name theirbox

    6

    Send a review link

    Open More → Review, publish the cut, then click Generate link. The client opens it in a browser and leaves notes pinned to exact frames. No account, no software.

    Pick how long the link stays open before you generate it.

    Advanced / Command line

    cairn review link --note "Client A" (add --role studio for internal notes the client cannot see)

    ?

    When something looks wrong

    • Working… dot - a copy is in flight or one computer is briefly offline. It fixes itself; give it a moment.
    • Needs attention - the Home card lists exactly what to click. If a project folder was deleted or moved, remove the project under Projects & paths and add the folder again.
    • A file shows Online only - open its ••• menu and choose Make available; it copies from your other computers.
    • Nothing is moving - the green Cairn icon in the system tray (near the clock) restarts everything. Right-click it for status.

    How it connects

    Computers connect directly when possible - on the same network a big copy takes minutes, not hours. When a direct line can't be found, an encrypted relay carries the files.

    Shortcuts & cheatsheet

    Keys

    • / focus search
    • ? toggle this panel
    • g h go to Home
    • g f go to files
    • g p go to People
    • g s go to settings
    • esc close panels and overlays

    CLI cheatsheet

    • cairn attach <folder>
    • cairn review publish --media cuts/v1.mp4
    • cairn review link --note "client"
    • cairn review export-markers --version 1 --out m.xml
    • cairn member add <device> <role>
    • cairn doctor
