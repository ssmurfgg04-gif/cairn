How to use Cairn

Cairn keeps your whole studio's footage in sync between computers - no upload sites, no hard drives in bags. Get started below; everything else happens automatically.

1

Get started (2 minutes)

  1. Click Add to Workspace above and pick your project folder (the one with your footage).
  2. Do the same on the other computers in your studio - they join the same project.
  3. That's it. Files you drop in the folder appear on every machine, automatically.

The folder works like a normal folder. Edit, save, move files as you always do - Cairn handles the copying.

2

Sending big files to each other

Replaces: SwissTransfer / WeTransfer waits (a 50 GB upload can take 5+ hours).

Drop the file in the project folder. It travels straight to the other computer - no cloud upload in the middle. On the same network this is minutes, not hours.

It even works through firewalls - if a direct line can't be found, an encrypted relay carries it.

3

Two people editing the same timeline

Replaces: "who has the newest version?" and merged-copy chaos.

Everyone works on their own copy of the timeline. Cairn's Timeline Merge puts the changes together automatically - frame-accurate, nothing lost, no "conflict copy 47" files.

From a terminal: cairn tl-merge --base old.otio --ours mine.otio --theirs theirs.otio

4

Seeing footage that isn't on this computer

Replaces: carrying hard drives between offices.

Files from other machines show up in the folder as lightweight placeholders - they look real, and the moment you open one, Cairn fetches it in the background. On Windows the folder is a real Explorer folder.

Need a file offline (a shoot, a flight)? Hover it and press the pin - it stays on this machine forever.

5

Editing heavy footage on a weak laptop

Replaces: waiting for renders, or being chained to the powerful machine.

Ask Cairn for a proxy - a small, light copy of a huge file that edits exactly the same. Cut on the laptop with proxies; the office machine swaps them back to full quality when it renders.

From a terminal: cairn proxy generate --media clip1.braw

6

Showing work to a client

Replaces: exporting, uploading, and emailing links just for feedback.

Publish the cut, then send a review link. The client opens it in their browser, plays the video, and leaves notes pinned to exact frames. No account, no software.

From a terminal: cairn review link --note "Client A" (add --role studio for internal notes the client cannot see)

?

When something looks wrong

  • Yellow dot / "reconnecting" - a sync is in flight or one machine is briefly offline. It fixes itself; give it a moment.
  • Red dot - open Settings and read the health panel. If a project folder was deleted or moved, remove it under Projects and add the folder again.
  • A file I need is a placeholder - hover it and press Recall; it materializes from the other machines.
  • Nothing syncing at all - the green cairn icon in the system tray (near the clock) restarts everything. Right-click it for status.

Shortcuts & cheatsheet

Keys

  • / focus search
  • ? toggle this panel
  • g d go to dashboard
  • g f go to files
  • g s go to settings
  • g h go to the how-to guide
  • esc close panels and overlays

CLI cheatsheet

  • cairn attach <folder>
  • cairn review publish --media cuts/v1.mp4
  • cairn review link --note "client"
  • cairn review export-markers --version 1 --out m.xml
  • cairn member add <device> <role>
  • cairn doctor

What the dot means

  • all files synced, safe to edit
  • syncing, chunks in flight
  • attention, open Settings
